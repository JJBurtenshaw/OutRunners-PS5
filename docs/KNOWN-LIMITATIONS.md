# Known limitations

## v1.0.0

- A compatible PS5 native homebrew environment
  is required.
- Compatibility across all firmware and loader
  versions has not been established.
- The original upstream CONTROLS menu is not
  available in this release.
- Users must provide their own legally obtained
  OutRunners World ROM set.
- Reproducible builds have been demonstrated
  on the reference Ubuntu/WSL2 host only.
- Network multiplayer and other upstream features
  should not be considered PS5-qualified unless
  specifically documented.

Please include the application version, PS5 firmware,
homebrew loader version and steps to reproduce
when reporting a problem.

Do not include copyrighted ROMs or personal saved
game data in public issue reports.
