# PS5 presentation artwork

The PlayStation 5 presentation artwork was
generated specifically for the OutRunners-PS5
homebrew project using OpenAI image generation.

The artwork is unofficial and is not presented
as original Sega promotional artwork.

The presentation assets are:

- sce_sys/icon0.png
- sce_sys/pic0.dds
- sce_sys/pic1.dds

These are the unchanged assets included in the
hardware-qualified Beta 2 release candidate.

No original arcade ROMs, extracted game sprites
or arcade music recordings are supplied as
presentation assets.
