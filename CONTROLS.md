# DualSense controls

## Driving and arcade input

| Control | Function |
|---|---|
| Left analogue stick | Steering |
| D-pad | Directional input |
| R2 | Accelerate |
| L2 | Brake |
| R1 | Shift up |
| L1 | Shift down |
| Square / Triangle | Music |
| Options | Start |
| Cross | Confirm |
| Circle | Back |

Input behaviour may depend on the current game
state and selected transmission mode.

## PS5-specific controls

| Control | Function |
|---|---|
| Touchpad click | Open pause menu / resume |
| R3 | Toggle FPS display |

The FPS display is disabled by default on
a fresh configuration.

## Pause menu

| Control | Function |
|---|---|
| D-pad up / down | Navigate |
| D-pad left / right | Adjust supported settings |
| Cross | Select / confirm |
| Circle | Back / resume |
| Touchpad click | Cancel / resume |
| R3 | Toggle FPS display |

The pause menu provides access to:

- Resume
- Restart
- Return to attract mode
- Display settings
- FPS display
- Exit

Some actions require confirmation or are only
available during appropriate game states.

## Local multiplayer

Local two-player operation has been verified
on physical PS5 hardware.

The native controller implementation maintains
two separate player controller slots.

Network multiplayer is not claimed as a
qualified v1.0.0 feature.

## Settings

The application supports persistent settings for
display mode, FPS display, steering dead zone,
steering sensitivity, steering speed, volume,
vibration and the both-radios option.

The initial settings are:

| Setting | Default |
|---|---|
| FPS display | Off |
| Steering dead zone | 10% |
| Steering sensitivity | 5/9 |
| Steering speed | 5/9 |
| Audio volume | 5/10 |
| Vibration | 50% |
| Both radios | Off |

Settings are stored in outrunners-settings.bin
within the application's writable storage.
