# Changelog

## v1.0.0 — First public release

- First stable public release of OutRunners-PS5.
- Promotes the hardware-qualified Beta 2 RC2 implementation.
- Native PS5 dashboard integration.
- Optimized software rendering, audio and DualSense support.
- Local two-player gameplay.
- Pause menu, configurable settings and persistent preferences.
- Automatic first-time game asset preparation.
- Custom PS5 presentation artwork.
- Complete installation, controls and build documentation.
- Corresponding-source distribution and verified reproducible builds.

The release is based on hardware-qualified RC2, with a final
in-game version-text correction. The runtime module and artwork
remain unchanged. Public metadata and documentation have been
updated for v1.0.0.

## v0.3.0-beta.2

- Native PS5 release candidate qualification.
- Local two-player gameplay verified.
- Gameplay, audio, settings, pause and FPS
  display verified on physical hardware.
- Unsupported CONTROLS menu removed.
- Exit and relaunch verified.
- Portable SDL2 reconstruction.
- Reproducible native engine and runtime builds.
- Two independent, byte-identical clean builds
  on the reference development host.
- Publication source and release artifacts frozen.
